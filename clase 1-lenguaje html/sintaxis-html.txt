Elemento (objeto) y Atributo (caracterìstica)
por ejemplo: <button class="boton-temario">Saber HTML</button>     Saber HTML es lo que ve el usuario
el boton y su texto saber HTML es el elementos
el Atributo es class clase y su valor es boton-temario

ejemplo: <a href="www.Mercadolibre.com.ar">ir a mercado libre</a href>   ir a mercado libre es lo que ve el usuario
href es host reference es el Atributo
y su valor es la direccion web de mercado libre.

etiqueta link tiene ref=  rel=  y crossorigin= como Atributos
etiqueta script tiene src= async= nonce=  crossorigin= como Atributos
etiqueta <a href="https://code.visualstudio.com/ target="_blank"> ir a visual studio code </a href> 
aqui hay dos Atributos href y target y el valor de target es nueva pagina.
