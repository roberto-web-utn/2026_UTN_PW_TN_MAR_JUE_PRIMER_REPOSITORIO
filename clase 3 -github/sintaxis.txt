github es un servicio de microsoft de repositorios en la nube. Git es una aplicación libre. 

github, para disponer de un repositorio en la nube - subir a la nube algo cada un mes por ejemplo, es como el curriculum

creamos una cuenta en github
creamos un repo y lo ponemos en publico, pues el TRABAJO PRACTICO deberá estar un repositorio

debemos estar en la rama main, si es la maestra le cambiamos el nombre.
git status nos dice la rama productiva

si el nombre es master, pasamos a main (ver barra azul inferior que figura la rama en uso)

git branch -M main   pues el repositorio se va a ir ramificando y la rama principal o productiva la llamo main

para añadir la dirección remota a nuestro repositorio local, así me subo con push a ese lugar en la nube:

git remote add origin https://github.com/roberto-web-utn/2026_UTN_PW_TN_MAR_JUE_PRIMER_REPOSITORIO

para saber si se ejecutó correctamente comando git remote -v

fetch es para traer codigos de la nube a mi compu con git pull o git fetch
push es para subir codigos a la nube con git push o git push -u origin si es la primera vez.
