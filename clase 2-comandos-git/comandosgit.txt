Pasos para crear un repositorio:

 

git init

    Crea un repositorio de git en el proyecto donde se ejecute

 

git add . 

    Añade los archivos sin seguimiento al respositorio de git

 

git commit -m 'mensaje descriptivo' es un disparo de la camara fotografica

    Versionar los cambios añadidos
cada vez que terminamos un feature, hacemos un commit, al final de cada feature, por ejemplo:
Feature 1: Agregar los botones desplegables con las cajas de HTML y CSS
Feature 2: Crear un formulario de contacto al final de la página.
Feature 3: Poner un botón para cambiar la página a "Modo Oscuro".
 

git branch -M main 

    Renombrar la rama principal

 

git remote add origin https://github.com/Matu-Dev-JS/2026_UTN_PWI_TN_MAR_JUE_PRIMER_REPOSITORIO.git

    Añadir una direccion remota (Direccion de repositorio remoto) a nuestro repositorio local

 

git remote -v

    Verificar la direccion remota a la que esta conectado nuestro repositorio local

 

git remote set-url origin <direccion del repositorio en la nube>

    Modificar la direccion remota de nuestro repositorio en la nube
